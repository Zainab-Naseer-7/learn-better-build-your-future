Self-Attention Mechanics & Vector Matrix Computation

In this lecture, we examine how the attention mechanism eliminates recurrent bottle-necks by computing all pairwise query-key compatibilities simultaneously using matrix multiplication.

# PyTorch Scaled Dot-Product Attention Core
def scaled_dot_product_attention(Q, K, V, mask=None):
    d_k = Q.size(-1)
    scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, -1e9)
    weights = F.softmax(scores, dim=-1)
    return torch.matmul(weights, V), weights

Core Takeaways

  • • Attention scale factor 1 / sqrt(d_k) prevents vanishing gradients at high vector dimensions.
  • • Query and Key dimensionality must match exactly, while Value vector dimensionality can vary.
  • • Causal autoregressive masking ensures generation tokens cannot peek into future timestep keys.
